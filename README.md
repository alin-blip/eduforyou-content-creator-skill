# eduforyou-content-creator

## What this skill does
This skill provides a complete operational guide and brand DNA framework for creating content for the **EduForYou** and **Market Your Skill** ecosystem. It equips the AI agent with the necessary knowledge to generate highly converting, brand-aligned content across various formats, strictly following the founder's unique voice and the brand's premium visual identity.

## When to use this skill
Use this skill whenever you are tasked with creating:
- Short-form video scripts (Reels, TikTok, Shorts)
- Long-form video scripts (YouTube, VSLs)
- Social media posts (Instagram, Facebook, LinkedIn)
- Email sequences
- Educational course content or walkthroughs
- AI image generation prompts for EduForYou brand assets

## Key capabilities
- **Founder's Voice Emulation:** Accurately replicates Alin-Florin Radu's "Wounded Warrior Turned Mentor" archetype, including his signature narrative patterns, specific vocabulary, and direct, conversational tone.
- **Teaching Framework:** Implements the strict `WHY -> WHAT -> HOW` teaching methodology, complete with transition patterns and validation checks ("Are sens ce zic?").
- **Visual Identity Rules:** Enforces the premium "Dark Navy & 3D Gold" visual aesthetic, providing specific color hex codes, typography rules, and 5 distinct layout templates.
- **Viral Content Frameworks:** Utilizes proven psychological frameworks (Cost Narration Hook, RSV Framework, 3-Step Hook) to maximize engagement and conversion.
- **End-to-End Workflows:** Contains step-by-step algorithms for generating complete social media posts, YouTube videos, and short-form content, including AI image prompts and SEO metadata.

Read the `SKILL.md` file to access the complete guidelines, templates, and examples. Apply the specific framework corresponding to the type of content requested by the user. Always verify the generated content against the "Checklist Final" provided at the end of the skill document.
